kroma.cli

CLI

kroma run starts one experiment. With no arguments, kroma prints help and exits.

On this page
  1. Command
  2. Flags
  3. From Python

Command

kroma run \
  --method_config kroma_scibert_envo_sweet \
  --llm meta-llama/Llama-3.3-70B-Instruct-Turbo-Free \
  --baseline

--method_config is the JSONL file name under experiments/configs/method/<llm>/. --llm is that directory name. Both are required.

Source: cli.py.

Flags

FlagMeaning
--method_configRequired. Config name, without .jsonl.
--llmRequired. Model directory under experiments/configs/method/.
--sizeFraction of the alignment to score. Default full.
--baselineSingle-model baseline.
--debateSeveral agents, several rounds. Omit it for one model.
--reasoningAsk the model to reason before yes or no.
--active_learningHold low-confidence pairs for review.
--compare_modelsCompare model settings from the config.
--bisimUse the bisimulation context path.

From Python

RunCommand(args).execute() -> None

RunCommand imports MatchingRun and runs it. If a model package is missing, it exits with the install line uv pip install '.[models]'.
