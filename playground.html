    Playground

    Describe two concepts, see the exact prompt KROMA builds for them, and ask a model you run whether they are the same.

    What runs where

    Everything runs in your browser. KROMA itself is Python and is not run here: the page builds the prompt with a port of KROMA's prompt builder (its templates are exported from the Python, so the text is identical), and reads the model's answer the way KROMA does. No model is hosted for this page, so Ask my model needs one you run yourself, for example Ollama on your computer.

    What it shows

    • The prompt is the whole of what KROMA sends to decide one pair: both concepts' names, parents, children, and synonyms. Change a field and the prompt changes with it, so you can see how much a missing parent or a synonym can matter.
    • The recorded answer for the example pairs is what the routed run of the Agentic Ontologist recorded, and which tier settled it.
    • Retrieval, voting across several agents, and refinement are not run here. See Retrieval and Refinement.
